# Changelog

## 0.1.0 — 2026-09-09

Initial open-source version.

- Reusable project JSON for floor polygons, walls, openings, fixtures, and room views.
- Procedural 3D furnishings, precise position and size controls, and footprint warnings.
- Sectionals, recliners, desk-beds, monitor configurations, and wall-mounted TVs.
- Independent saved checkpoints, working drafts, undo/redo, and project imports.
- Floor-plan and walk-through views, PNG images, and GLB exports in meters.
- Fictional demo, unit and browser tests, CI, and contributor documentation.
